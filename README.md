# The World in One Day — Monday 23 November 2026 (v3)

One image that sums up 23 November's world news, for the make.fun bounty
[news-image-20261123](https://make.fun/bounty/news-image-20261123).

`main.ts` (Node 22) runs `draw_frontpage.py` (Python + PIL, no network) and
writes one deterministic 1024×1024 PNG to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`).

v3 is a fresh renderer, written from scratch: 33 date-checked stories across
6 regions, 3 illustrated leads, 10 mid cards, a world map with 13 pins, a UTC
timeline, a DATE CHECK box and a CONFIRMED / REPORTED / FORECAST legend.
vs v2 (round 2: #269, 70.7316%): bigger and richer lead illustrations,
larger headlines, shorter summaries so nothing is cramped, more breathing
room, and a bigger map — execution, not formula, is the differentiator in a
field full of "World in One Day" front pages.

Run: `node main.ts` (needs `python3` + PIL on PATH).
